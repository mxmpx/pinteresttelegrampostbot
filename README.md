# Pinterest to Telegram Auto-Poster (GUI)

Desktop-приложение на Python (Tkinter) для автоматического отслеживания новых пинов в Pinterest и их публикации в Telegram-канал. Работает через RSS-ленту без необходимости получать официальные API-ключи Pinterest.

---

## ✨ Основные возможности

* **Удобный AMOLED GUI:** Тёмный минималистичный интерфейс с адаптивным Canvas без задержек при изменении размера окна.
* **Без API Pinterest:** Парсинг открытой RSS-ленты пользователя — никаких сложного создания приложений и авторизаций.
* **Высокое качество:** Автоматический поиск и загрузка оригиналов изображений (`/originals/`) с запасным фолбэком на HD.
* **Умная очистка ссылок:** Автоматическое извлечение юзернеймов и ID каналов из сырых ссылок любого формата (например, `https://t.me/channel` -> `@channel`).
* **Фильтрация и дубликаты:** Отправка только новых пинов, опубликованных после запуска бота, с сохранением истории в `seen_pins.json`.
* **Галерея и Логи:** Встроенная панель предварительного просмотра отправленных фото и логирование всех действий в реальном времени.
* **Многопоточность:** Графический интерфейс работает плавно и не зависает во время загрузки или ожидания публикаций.

---

## 🛠 Требования и зависимость

Для работы программы нужен **Python 3.8+** и две сторонние библиотеки:

* `requests` — для работы с HTTP-запросами к Telegram API и Pinterest.
* `Pillow` — для обработки превью изображений в интерфейсе.

## 🚀 Быстрый старт

### 1. Установка

Клонируйте репозиторий и установите необходимые библиотеки:

```bash
git clone https://github.com/your-username/pinterest-tg-bot.git
cd pinterest-tg-bot
pip install requests pillow

```

### 2. Запуск

Запустите главный файл приложения:

```bash
python main.py

```

---

## ⚙️ Инструкция по настройке

1. **Telegram Bot Token:** Получите токен у [@BotFather](https://t.me/BotFather) в Telegram.
2. **Права в канале:** Добавьте созданного бота в администраторы вашего Telegram-канала с правом отправки сообщений.
3. **Заполнение полей в GUI:**
* **Bot Token:** Ваш токен от BotFather.
* **Канал:** `@username_kanala` или ссылка на канал.
* **Pinterest:** Юзернейм аккаунта или ссылка на профиль Pinterest.
* **Интервал:** Частота проверки обновлений в минутах (по умолчанию `60`).


4. Нажмите кнопку **▶ ЗАПУСТИТЬ БОТА**. Конфигурация автоматически сохранится в `gui_config.json`.

---

## 📁 Структура файлов

* `main.py` — основной файл приложения (GUI + логика парсера).
* `gui_config.json` — сохраненные настройки формы (создается автоматически).
* `seen_pins.json` — база ID уже отправленных пинов для предотвращения дублей (создается автоматически).
